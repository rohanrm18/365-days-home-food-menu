# Dish photos (optional)

Until a photo is added, the app shows a coloured tile with the dish name and an emoji.

To use a real photo for a dish, add a JPG here named after the dish in lowercase with
underscores, for example:

- `poha.jpg`
- `puran_poli_and_amti.jpg`
- `chicken_curry_rice_and_salad.jpg`
- `ukadiche_modak.jpg`

The app picks the photo up automatically on the next build. Wide (16:9) photos under 300 KB work best.
